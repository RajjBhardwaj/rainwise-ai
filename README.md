## Tech Stack

- **Frontend**: React + Vite + Tailwind CSS + Leaflet + Recharts
- **Backend**: FastAPI (Python)
- **ML**: scikit-learn (trained in Google Colab)
- **Weather API**: Open-Meteo
- **Database**: None for now (SQLite later if needed)

## Project Structure

- `backend/` — FastAPI backend
- `frontend/` — React frontend
- `ml/` — dataset, notebooks, trained models
